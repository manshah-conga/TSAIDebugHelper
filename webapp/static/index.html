Normalize a debug log

Upload a raw Salesforce debug log to get a compact, normalized JSON version -- no org connection, no Apex/Flow source, no metadata needed. The raw log is used only in memory and never stored; only the normalized JSON can be kept. Once normalized, you can download it, keep it in the library below, or hand it to Claude via the MCP server to get an RCA and suggested resolution from the log alone.

Create an API token for the MCP server

The MCP server authenticates to this app with an API token. A token inherits your role, so a reader token can only read, a user token can also connect orgs and file incidents. The token is shown once, on creation -- copy it immediately; it can't be retrieved later, only revoked.
